# JAVBED

**Minecraft launchers, tools, and random stuff we thought should exist.**

JAVBED is an open-source organization focused on building tools for Minecraft Java and Bedrock. We make launchers, utilities, and other projects that make messing with Minecraft easier.


## Why JAVBED?

**JAV**a + **BED**rock = **JAVBED**

Pretty simple.

## Contributing

Most of our projects are open source. If you find a bug, have an idea, or want to improve something, open an issue or pull request.
